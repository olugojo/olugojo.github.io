# Ojo Olugbenga Toheeb — portfolio

A responsive, dependency-free static website for GitHub Pages. Open index.html to preview locally.

## Publish
Copy index.html, style.css, and favicon.svg into the root of your olugojo.github.io repository. Commit the files. In repository Settings → Pages, select the branch containing these files and the root folder if branch publishing is used.

## Make it yours
- The project section features TOHMAH & Sons, K-Maytos Website, Personal Portfolio, and Enterprise Payroll. Enterprise Payroll links directly to its Render application.
- Your name, trainee background, email, GitHub, and LinkedIn were retained from the original site. Confirm contact details before publishing.
- To add a portrait, place a photo in the repository and use a normal img element with meaningful alt text. The old visitor-local photo upload has been removed because it did not publish a portrait for other visitors.
- Update the copyright year as needed.

## Design and quality improvements
Clear typography and hierarchy; restrained green and neutral palette; responsive layouts; visible keyboard focus; skip link; semantic sections and headings; reduced-motion support; corrected page metadata; local SVG favicon. No fonts, scripts, frameworks, or image services are required.

## Validation
Checked local asset paths, section links, single h1, and removal of placeholder repository links and browser-only uploads. Review in your target browsers and test keyboard navigation before publishing. External profile ownership and contact delivery have not been verified.
